Holy Grail Layout

Level 4 implementation using Flexbox and CSS Grid.

Flexbox

One-dimensional layout model. Controls alignment and distribution of items along a single axis.

CSS Grid

Two-dimensional layout system. Defines both rows and columns, enabling complex full-page layouts.

Responsiveness

Both systems support responsive layouts. This page uses four breakpoints with distinct layout behavior at each.

Collapsible Sidebars

Left and right sidebars collapse and expand via a class toggle handled with minimal JavaScript.

Custom Properties

Layout dimensions are stored as CSS custom properties, keeping code DRY and easy to maintain.

Subgrid

The Grid version uses subgrid to align card internals across the whole grid where the browser supports it.
